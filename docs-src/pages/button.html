Link as button
<button data-variant="primary">Submit</button>
<a class="btn" href="/docs">A link dressed as a button</a>

Attributes

data-variant accepts primary, ghost, or danger. data-size accepts small or large. Data attributes keep extension markup valid on native HTML elements.

Notes

Ghost has deliberately zero rest affordance — toolbars and icon rows, not the lone action on a page. Disabled is the same fill at reduced opacity.

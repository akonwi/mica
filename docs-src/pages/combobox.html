<m-combobox>
  <input list="langs" placeholder="Language&#8230;" />
  <datalist id="langs">
    <option>Ard</option>
    <option>Go</option>
  </datalist>
</m-combobox>

<script type="module" src="mica/combobox.js"></script>

Notes

The options are the author's datalist markup — the module presents them, it doesn't invent them. It wires the ARIA combobox pattern: aria-expanded, aria-activedescendant, substring filtering on input, Arrow/Enter/Esc keys, selection dispatches real input/change events. The listbox positions inside the wrapper (no top layer), so it works in every browser mica supports.

The datalist may be populated asynchronously — a search-backed combobox that renders options as results arrive just works. The module observes the datalist and rebuilds its listbox when options change, and selection writes through the native value setter so frameworks that track controlled inputs (React) observe it.

Reference — current controls

1 — Square Target (designer's pick)

Concentric squares: hollow socket unchecked, filled tile with a bright square ring when checked.

2 — Diamond Socket

Hollow diamond unchecked, solid bright diamond on the primary fill when checked. Angular but unmistakably not a checkbox.

3 — Circular Aperture

Square chassis, round socket — keeps the learned "round dot = single choice" cue inside the square language.

All three are the same native input — only unlayered page CSS differs, which is itself the mica customization story at work.

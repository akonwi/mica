Markup anatomy

nav[data-navigation-menu] accepts direct links and native details groups. Each group has a summary and an authored [data-nav-panel]. Rich layouts compose ordinary links, headings, and Mica layout elements.

The header module adds Escape, outside-click dismissal, and panel placement. Normal Tab navigation remains available. Panels open on click, touch, Enter, or Space.
